# Тренажёр гамбита Руссо

Учим гамбит Руссо за чёрных: 1. e4 e5 2. Nf3 Nc6 3. Bc4 f5.
За белых ходит компьютер, ты — за чёрных мышкой.

## Запуск

1. Один раз положи токен lichess в файл `lichess_token.txt` (как получить — ниже).
2. Запусти `run.cmd` — откроется браузер.

## Токен lichess

С 3 марта 2026 года lichess отдаёт статистику дебютов только с токеном.

1. Войди на lichess.org в свой аккаунт.
2. Открой https://lichess.org/account/oauth/token/create
3. Впиши любое название, галочки не ставь, нажми «Создать».
4. Скопируй токен (начинается с `lip_`) в файл `lichess_token.txt` в папке проекта.

Файл `lichess_token.txt` не попадает в git — он записан в `.gitignore`.

## Как идёт тренировка

- Доска открывается чёрными вниз.
- Через полсекунды белые играют e4, ты отвечаешь e5.
- Дальше так же: Nf3 — ты Nc6, Bc4 — ты f5.
- Не тот ход — фигура вернётся на место, над списком ходов появится подсказка.
- После f5 белые берут три самых популярных хода из базы lichess (все игроки, не мастера) и играют случайный из них.
- Дальше ходи как хочешь — белые отвечают так же, по статистике lichess.
- Если статистику получить не удалось, автоигра заканчивается: белые больше сами не ходят, двигаешь фигуры сам за обе стороны. Причина пишется над списком ходов.

## Кнопки

- «Отменить» — забрать свой ход вместе с ответом белых.
- «Очистить» — начать гамбит заново.
- Загрузка PGN или дебюта из списка выключает автоигру.

## Файлы

- `index.html` — тренажёр.
- `server.py` — локальный сервер: отдаёт страницу и запрашивает статистику у lichess с твоим токеном.
- `run.cmd` — запускает `server.py` и открывает браузер.
- `lichess_token.txt` — твой токен lichess (создаёшь сам).
