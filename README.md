# Тренажёр Итальянской партии

Учим Итальянскую партию за белых: 1. e4 e5 2. Nf3 Nc6 3. Bc4.
Ты ходишь за белых мышкой, за чёрных ходит компьютер.

## Запуск

1. Один раз положи токен lichess в файл `lichess_token.txt` (как получить — ниже).
2. Запусти `run.cmd` — откроется браузер.

## Токен lichess

С 3 марта 2026 года lichess отдаёт статистику дебютов только с токеном.

1. Войди на lichess.org в свой аккаунт.
2. Открой https://lichess.org/account/oauth/token/create
3. Впиши любое название, галочки не ставь, нажми «Создать».
4. Скопируй токен (начинается с `lip_`) в файл `lichess_token.txt` в папке проекта.

Файл `lichess_token.txt` не попадает в git — он записан в `.gitignore`.

## Как идёт тренировка

- Доска открывается белыми вниз.
- Ты играешь e4, через полсекунды чёрные отвечают e5.
- Дальше так же: ты Nf3 — чёрные Nc6, затем ты Bc4.
- Не тот ход — фигура вернётся на место, над списком ходов появится подсказка.
- После Bc4 чёрные берут два самых популярных хода из базы lichess (все игроки, не мастера) и выбирают один с учётом популярности: чем чаще ход играют, тем чаще он выпадает.
- Дальше ходи как хочешь — чёрные отвечают так же, по статистике lichess.
- Если статистику получить не удалось, автоигра заканчивается: чёрные больше сами не ходят, двигаешь фигуры сам за обе стороны. Причина пишется над списком ходов.

## Кнопки

- «Отменить» — забрать свой ход вместе с ответом чёрных.
- «Очистить» — начать партию заново.
- Загрузка PGN или дебюта из списка выключает автоигру.

## Файлы

- `index.html` — тренажёр.
- `server.py` — локальный сервер: отдаёт страницу и запрашивает статистику у lichess с твоим токеном.
- `run.cmd` — запускает `server.py` и открывает браузер.
- `lichess_token.txt` — твой токен lichess (создаёшь сам).
